## 3. GitHub Actions Hardening Workflow Architecture

The `.github/workflows/hardening-gates.yml` workflow orchestrates three parallelized and gated stages:
1. **`coverage-gate`**: Builds VeriFast with OCaml and Rust coverage flags enabled, executing `./scripts/run_coverage.sh --full --rust-cov`.
2. **`soundness-and-rocq-gate`**: Compiles Rocq metatheory proofs (`make rocq_metatheory_proofs`), executes negative soundness suites, validates Gallina emitter mappings via `tests/rust/rocq_check.py`, and checks specification non-vacuity.
3. **`mutation-cross-prover-fuzz-gate`**: Executes two-tier mutation tests, differential testing against Miri, grammar fuzzing, and runs `scripts/check_hardening_gates.py` to assert 100% gate satisfaction before merging.
